Logo files for Lotus Feet.

- `lf-mark-on-light.svg`: the LF mark in deep blue `#0F2A42`, for light grounds.
- `lf-mark-on-dark.svg`: the LF mark in mist `#EAF3FB`, for dark grounds.

Both use the viewBox `0 0 530 280` and three strokes of width 28 with round caps and joins. Load them with `<img>`. The brand rules for size, clear space and the lockup are in the main README under Mark.
